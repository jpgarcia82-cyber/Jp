# 03 — Munición Cimiento (biblioteca de datos e ideas)

Cada artículo, estudio o conversación con un dueño de PYME que te sirva, va aquí. Es lo que
alimenta los posts del lunes y las respuestas a objeciones.

## Instrucciones del Proyecto

```
Este proyecto guarda munición para el contenido y las ventas de Cimiento. Cuando agregue una
entrada, solo confirma que la guardaste y dime a qué segmento sirve (sin nada / ERP mal
instalado / consultor insatisfactorio). Cuando te pregunte, busca entre todas las entradas y
cita de qué fuente viene cada idea. Si una entrada no trae fuente verificable, márcala como
"solo contexto, no para copy público".
```

## Formato de entrada

```
Fuente: [título + link]
Tipo: estudio / artículo / conversación con prospecto / experiencia propia
Dato o idea clave: [...]
Cita textual: "[...]"
Segmento: sin nada / ERP mal instalado / consultor insatisfactorio
```

> Las conversaciones con prospectos son oro: anota la frase exacta con que describen su dolor
> (sin nombre de la empresa) — ese es el lenguaje que debe usar la landing.

## Consultas

```
¿Qué munición tengo para el segmento "ERP mal instalado"? 3 puntos con fuente.
Dame las 5 frases textuales de prospectos que más se repiten.
```
