# 3. El agente de revisión — "Mi revisión"

Crea primero el Proyecto **"Mi revisión"** (sin instrucciones especiales; ahí se guardan las notas).

## Tarea diaria

```
Todos los días a las 10:00 PM, pregúntame: qué fue bien hoy, qué no, y una cosa concreta
que podría mejorar mañana. Guarda mi respuesta en el proyecto "Mi revisión" con la fecha.
```

## Tarea semanal

```
Cada domingo a las 7:00 PM, revisa todas mis notas de revisión diaria de esta semana en el
proyecto "Mi revisión" y dame: 3 patrones que se repiten (positivos o negativos), y 1 cosa
concreta y específica para cambiar la semana que viene — no un consejo genérico.
```

## Formato sugerido para tu respuesta diaria

```
Fecha: [AAAA-MM-DD]
Fue bien: ...
No fue bien: ...
Mañana mejoro: ...
```
