# 5. La biblioteca de vida — "Lo que aprendo"

## Paso 1 — Instrucciones del Proyecto ("Lo que aprendo")

```
Este proyecto guarda resúmenes de lo que leo/veo. Cuando agregue una entrada nueva, solo
confírmame que la guardaste, no la reescribas. Cuando te pregunte sobre un tema, busca entre
todas las entradas guardadas y cita de qué libro/artículo/video viene cada idea que mencionas.
```

## Paso 2 — Formato de entrada (cada vez que termines algo)

```
Libro/artículo/video: [título]
Idea clave: [la idea central que te quedó]
Cita que me sirvió: "[cita textual, si aplica]"
```

## Paso 3 — Consulta libre

```
¿Qué he leído/visto sobre [tema]?
```

```
Busca ideas sobre [tema] que haya guardado y resúmelas en 3 puntos.
```
