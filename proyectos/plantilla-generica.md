# Plantilla genérica — para cualquier otra idea

Úsala para adaptar cualquiera de las otras ideas (ej. "cazador de suscripciones", "de llamada a factura").

```
Crea un Proyecto llamado "[nombre]". Instrucciones fijas: [qué debe hacer cada vez que lo invoco,
qué datos debe usar, en qué formato debe responder, y qué debe decir si falta información].
Si necesita datos en vivo (correo/calendario/drive), conecta [herramienta] en Ajustes → Conectores
antes de crear el proyecto. Si debe repetirse solo, agrega: "Programa esto cada [frecuencia] a las [hora]".
```

## Checklist para rellenarla

- **Qué hace** cada vez que lo invocas (una frase con verbo).
- **Qué datos usa** (archivos subidos, correo, calendario, Drive).
- **Formato de salida** (lista, tabla, 3 puntos, una pantalla…).
- **Qué hacer si falta información** (decirlo explícitamente, nunca inventar).
- **Frecuencia** (si debe correr solo: cada cuánto y a qué hora).
