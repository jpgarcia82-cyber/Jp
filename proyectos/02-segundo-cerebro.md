# 2. El segundo cerebro — "Mi papeleo"

## Paso 1 — Instrucciones del Proyecto ("Mi papeleo")

```
Este proyecto contiene mi papeleo personal: contratos, pólizas, notas sueltas.
Cuando te pregunte algo, respóndeme citando el documento exacto de donde sacaste la respuesta
(nombre del archivo y, si aplica, la cláusula/sección). Si la respuesta no está en ningún
documento subido, dímelo explícitamente — no inventes ni asumas un dato que no está ahí.
```

## Paso 2 — Sube tus documentos

Sube al Proyecto tus PDFs/documentos (contratos, pólizas, notas). No hace falta ordenarlos antes.

## Preguntas de ejemplo

```
¿Cuándo vence mi seguro del coche?
```

```
¿Qué cláusulas tiene el contrato de alquiler sobre la fianza?
```

```
Resume en 3 líneas qué cubre mi póliza de hogar, y cita de qué documento lo sacaste.
```
