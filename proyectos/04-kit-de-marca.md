# 4. El kit de marca — "Mi marca"

## Paso 1 — Crea el Proyecto y sube tus textos

Crea el Proyecto **"Mi marca"** y sube 5-10 textos tuyos reales (web, posts, propuestas que ya hayas escrito).

## Paso 2 — Prompt para construir el kit

```
Con los textos que subí a este proyecto, define mi kit de marca:
- 3 colores (en hex), justificando por qué calzan con el tono de los textos.
- 2 fuentes que combinen bien entre sí (una para títulos, una para cuerpo).
- 3 reglas de tono que deba seguir siempre al escribir algo para mí (ej. "nunca uses jerga
  corporativa", "frases cortas, voz activa").
Guarda esto como referencia fija del proyecto para usar en cualquier pieza futura.
```

> Tip: copia el kit resultante y pégalo también en las **Instrucciones del Proyecto**, así queda
> fijo aunque la conversación original se pierda.

## Paso 3 — Uso diario

```
Hazme un post de LinkedIn con mi kit de marca sobre [tema].
```

```
Escribe una newsletter con mi estilo anunciando [lo que sea].
```
